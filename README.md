# ⚽ Touchline — Explainable Match Intelligence Studio

**Microsoft × Premier League "Inside the Game: Developer Hackathon" submission.**

Touchline turns a streaming synthetic football event feed into explainable match
intelligence, live broadcast narratives, and personalized fan experiences. A
multi-agent intelligence layer (tactical analyst, live commentator, recap writer)
explains *why* each moment matters, with evidence ids on every insight, rendered
into a live broadcast studio UI with Analyst / Casual / Player-focus personas and
a multilingual commentary ticker.

> **Synthetic data mandate:** every event in this project is generated by our own
> simulator for two fictional clubs (Kwara Dynamos vs Coastal Rovers). No real
> Premier League data, footage, marks, or statistics are ingested or redistributed.

## The 5-stage pipeline

```
[1 INGEST]  Synthetic event simulator (105m x 68m pitch, positional (x, y, t) telemetry,
            passes / shots / tackles / interceptions / carries / fouls / corners / pressure)
    |
[2 INTERPRET] Metrics engine: direction-aware Expected Goals (xG), Pass Difficulty
            Rating (PDR), possession, pass accuracy
    |
[3 EXPLAIN] Control-vs-Chaos Index, PPDA pressing meter, line-breaking-pass detection
    |
[4 AGENTS]  Multi-agent orchestration over a shared blackboard:
            Tactical Analyst · Live Commentator · Recap Writer
            (Microsoft Foundry / Azure OpenAI adapter with deterministic fallback)
    |
[5 RENDER & PERSONALIZE] Broadcast studio UI: scorebug HUD, 2D pitch visualizer,
            Analyst / Casual / Player-focus personas, multilingual ticker (EN ES FR DE AR HI),
            automated full-time recap
```

## Quickstart

**Option A - replay the precomputed match (no backend needed):**

```
cd frontend && python3 -m http.server 8080
# open http://localhost:8080  -> press "Kick off"
```
`frontend/demo/match.json` is a full precomputed match (events + metrics + agent
insights) produced by `scripts/export_match.py`, so the studio runs on any static host.

**Option B - full live API (event streaming):**

```
pip install -r requirements.txt
uvicorn backend.api.server:app --reload --port 8000
# open http://localhost:8000
```

**Option C - Docker:**

```
docker compose up --build   # then open http://localhost:8000
```

## Architecture

- `backend/simulator/generator.py` - synthetic match event generator (stage 1)
- `backend/analytics/metrics.py` - streaming metrics engine (stages 2-3)
- `backend/agents/agents.py` - orchestrator + 3 specialized agents over a shared
  blackboard, with per-agent cooldowns and resilient fallbacks (stage 4). Setting
  `AZURE_OPENAI_ENDPOINT` + `AZURE_OPENAI_API_KEY` switches narratives to
  Microsoft Foundry / Azure OpenAI; templates keep the demo working without keys.
- `backend/api/server.py` - FastAPI + Server-Sent-Events streaming, CORS, static
  hosting of the studio UI
- `frontend/` - broadcast studio (vanilla JS, canvas pitch, zero build step)
- `azure-container-app.yaml` - Azure Container Apps deployment manifest
- `tests/` - pytest suite for the metrics engine

## Microsoft technology story

- **Microsoft Foundry (Azure AI Foundry)** - LLM narrative generation adapter in
  `backend/agents/agents.py` (`_llm`), designed for Foundry-hosted deployments.
- **Agent design patterns** - role delegation, shared-state blackboard, handoffs,
  per-agent cooldowns, error-resilient orchestration.
- **Azure cloud-native** - containerized FastAPI service, health endpoint,
  Azure Container Apps manifest (`azure-container-app.yaml`), docker-compose.
- **Event-driven streaming** - SSE event bus (drop-in for Azure Event Hubs in
  production; see `ARCHITECTURE.md`).
